# Finalize automatically after a correction window, review later changes

The user selected provisional gameweek results until all assigned fixtures are settled, followed by a configurable correction window initially set to 24 hours (Q14, 2026-09-18). Finalize automatically only with complete required data and no unresolved issues; later provider corrections create an admin-review case, and reopening is an audited action.

This balances autonomous operation with stable published results instead of perpetual silent changes or mandatory manual finalization of every gameweek. Retain earlier result revisions. D13 resolves timer resets, issue review and downstream consequences in [result lifecycle](../result-lifecycle.md); ADR-0012/0013 record shared correction scope and separate prize fulfillment.
