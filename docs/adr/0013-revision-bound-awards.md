# Bind awards to result revisions and separate fulfillment

Under D06, prize proposals reference a finalized revision and require eligibility review and approval before recorded fulfillment. Corrections freeze unfulfilled awards and create discrepancy cases for fulfilled ones, rather than treating prize payments as another reversible score projection.

Launch provides real award administration and external fulfillment records; a wallet or automated payout system would add a separate custody, reconciliation and commercial boundary. These require a later explicit design, not a feature flag.
