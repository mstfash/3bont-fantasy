# Share football corrections while finalizing each fantasy game independently

Under D01/D13, real-world factual overrides apply at shared fixture scope, while each fantasy competition retains its published result revision until its own finality policy permits replacement. Private factual forks would make the same footballer both score and not score the same real goal; automatically reopening every finalized game would undermine awards and audit.

A correction previews all affected games. Provisional results recalculate; finalized games create review cases. Future scoring-rule differences stay in competition configuration.
