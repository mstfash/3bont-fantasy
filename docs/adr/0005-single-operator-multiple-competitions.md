# One operator manages multiple competitions

The user selected one operator managing multiple competitions for the first release (Q01, 2026-09-18). Choose this operating model over independent customer organizations to fit the client product and avoid building customer isolation and self-service organization management before they are required.

The operator may have multiple staff accounts, with permissions still to be defined. Competition boundaries remain explicit; adding independent customers later would require a deliberate isolation and migration design, not merely a feature toggle.
