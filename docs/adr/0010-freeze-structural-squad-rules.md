# Freeze structural squad rules after the first gameweek locks

The user chose to keep squad size, position quotas, permitted formations and starting budget fixed after the competition's first gameweek locks (Q13a, 2026-09-18). Edit those settings in drafts/new competitions instead of building a mid-season migration, notice and squad-repair workflow that can invalidate existing entries.

This is a deliberate boundary on admin configuration, not hardcoding the defaults. Scoring still uses future versions and explicit historical replay under Q13; entry-count limits retain their separate Q06/Q06a policy. This decision does not resolve club-cap changes, player reclassification, transfer/chip-rule changes or other configuration categories.
