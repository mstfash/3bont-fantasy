# Slice 25 — Review retained provider responses

Implementation 2026-09-19, no new migration. The gateway now retains bounded malformed responses as diagnostic evidence instead of discarding their content. Secret redaction covers JSON keys, values and non-JSON response text. Invalid content remains invalid and cannot establish identity or fantasy facts; over-limit bodies and requests without a response retain their charged attempt without a body.

Global data staff can open an attempt's Arabic/English evidence page and download its redacted JSON with request timing, HTTP status, original transport checksum and first stored-content time. Repeated identical responses can share evidence while retaining separate attempt times. The display escapes source markup and limits its preview to 32,000 characters; authenticated download provides the complete bounded record. No credentials or raw response are sent to participant pages.

Database proof covers malformed-content retention, secret-valued keys, deduplication, charged failures, scoped access rejection and missing attempts. Full formatting/lint/strict-type/production-build checks and 71 unit tests pass; disposable PostgreSQL passes 57 application cases/subcases. The browser evidence view/download, anonymous rejection and Arabic mobile checks passed, followed by the complete regression through MFA.
