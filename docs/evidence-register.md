## Reuse screening

The original request asked about an existing foundation. Initial public-source screening found:

| Candidate                                                                     | Observed from repository                                                                                                                                     | Assessment                                                                                                                                                                                      |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Fantasy Manager fork](https://github.com/sayan-bhattacharya/fantasy-manager) | README advertises self-hosting, league plugins, configurable budget/transfer limits and historical squads; installation links point to Lukasdotcom upstream. | Worth a bounded upstream audit. README does not establish our multi-entry, two Free Hit baselines, deadline races or finality behavior. Fork/upstream provenance must be resolved before reuse. |
| [Sports Fantasy League](https://github.com/salihgueler/sports-fantasy-league) | Described as a multi-sport fantasy league engine with squads, transfers and live scoring.                                                                    | Candidate only. No code execution, license audit or compatibility proof performed.                                                                                                              |

Decision D15: build the agreed domain behind a narrow provider boundary and reuse mature infrastructure. A whole-engine fork is not selected based on marketing/readme similarity. Before investing in an alternative foundation, run a bounded comparison against A10/A31/A35–A42 and correction fan-out; record version, license, tests, migration/adaptation cost and update ownership. No assertion that either candidate is maintained, secure, bug-free or unsuitable has been established.
