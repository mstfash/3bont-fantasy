# First-release scope

The user's corrected Q03 answer requires **all named modules except native apps**. This supersedes the briefly selected smaller launch. Delegation on 2026-09-18 selects the details below; it does not reverse that launch choice.

| Capability            | Launch definition                                                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------------- |
| Core fantasy/admin    | Configurable entries, squads, transfers, all four chips, scoring, deadlines, rules, corrections and audit |
| Fantasy prices        | Reviewed initial prices, exact selling policy, simulated/calibrated performance updates                   |
| Real-world valuations | Sourced separate valuations with date/currency/availability; usable data source is a launch gate          |
| Arabic and English    | Participant/admin UI, public content and transactional email, RTL/LTR                                     |
| H2H                   | Fixed-roster round-robin editions, byes/forfeits, revised outcomes                                        |
| Prizes                | Published terms, eligibility/ties, review/approval and recorded external fulfillment                      |
| Achievements          | Configurable built-in condition catalogue with correction/revocation                                      |
| User chat             | Moderated membership-scoped group text rooms                                                              |
| Sponsors              | Localized campaigns/placements/assets and aggregate reporting                                             |
| Responsive web        | Mobile and desktop with accessible online competitive flows                                               |
| Native iOS/Android    | Deferred; future clients use versioned application contracts                                              |

[Game rules](game-rules.md) and [module specifications](module-specifications.md) are canonical details. Bonus is a supported configurable category, default disabled until precise formula/data/ties are validated (Q12d); active bonus is not a launch prerequisite.

Direct messages, participant-uploaded chat files, wallets/entry fees, automatic payment rails, personalized ad targeting, combined-real-league games and independent customer tenants are outside this selected first-release definition. They are not secretly promised by toggles or placeholder screens.

Implementation stages are internal sequencing; P5 modules must be complete before launch. No delivery date, capacity guarantee or fixed-price commercial agreement has been made.
