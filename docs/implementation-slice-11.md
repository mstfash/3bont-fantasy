# Slice 11 — Sponsor campaigns

Implemented and verified, 2026-09-19. Migration 0011 is applied locally and immutable.

Sponsor managers upload authorized static PNG/JPEG/WebP artwork within a competition scope or the global header scope. The server bounds bytes, checks raster signatures, rejects animation and oversized dimensions, decodes under a pixel/channel limit, strips metadata and stores an immutable normalized WebP of at most 1 MB. Before a campaign is live, artwork previews require scoped staff access. Decoding and output behavior follow the [Sharp constructor](https://sharp.pixelplumbing.com/api-constructor/) and [output documentation](https://sharp.pixelplumbing.com/api-output/).

Bilingual drafts select approved artwork, an HTTPS destination, placement, Cairo schedule and priority. Publication records an approval reference. Published creative must be paused before editing and reviewed again before publication. The global header and competition/prize page slots use deterministic highest-priority selection, with stable ID order for ties. Sponsor authority cannot modify gameplay or prize eligibility. Public placements visibly disclose sponsorship and isolate outbound links from the opener/referrer.

Reporting counts approximate impressions after half the placement is visible for one second and link activations as clicks. Known crawler user agents are excluded; signed ten-minute page tokens bind campaign revision and locale, with one accepted event of each type per token. Paused, expired or superseded campaigns reject new events. No account IDs, IP addresses or advertising cookies are stored for reporting. Repeated visits and unknown bots can still inflate counts: these are not billing-grade metrics. Daily aggregates use Cairo calendar dates; the screen reports the last 30 calendar days by revision and language. Short-lived receipt cleanup runs with the hourly worker maintenance.

Normalized artwork is stored in PostgreSQL so the initial deployment and backup cover the same durable state. Binary payloads stay out of contracts, audit and command receipts. If campaign volume makes database media storage costly, immutable asset IDs and the delivery route provide a migration boundary to an object store.

Full formatting/lint/types/build/unit checks pass. Disposable database tests cover format/dimensions, scoped/private previews, publication and pause/edit lifecycle, competing priorities, token tampering/expiry/bots/early impressions and concurrent deduplication. Browser verification passes artwork upload, protected preview, bilingual publication, disclosure, Arabic mobile layout and pausing. Anonymous ingress rate limits and measured reporting load remain deployment gates; this does not claim resistance to distributed traffic abuse.
